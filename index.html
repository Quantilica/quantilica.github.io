※ Quantilica

Infraestrutura open-source para coletar, normalizar e analisar
dados públicos brasileiros em Python — do IBGE ao BCB, do DATASUS ao Tesouro Nacional, com manifestação de provenição SHA-256 em cada download.

Python ≥ 3.12 MIT License Proveniência SHA-256 Polars / PyArrow

O que nos move

Três pilares que guiam cada linha de código, cada pipeline e cada decisão de produto.

Transparência Dados abertos, código aberto, metodologia documentada — nada escondido.
Precisão Pipelines auditáveis, manifestos SHA-256, sem "magic numbers".
Acessibilidade APIs simples, documentação clara, curva de entrada baixa.

Instalação

Dois fluxos canônicos: pacotes ancorados no PyPI e fetchers distribuídos pelo índice próprio (PEP 503 hospedado no GitHub Pages).

# 1. CLI unificada e núcleo — direto do PyPI
pip install quantilica-cli (traz o quantilica-core)

# 2. Fetchers sob demanda — via índice próprio
quantilica install bcb-sgs
quantilica install rtn
# Alternativa manual (sem a CLI), apontando pip/uv para o índice:
uv pip install rtn-fetcher --index-url https://index.quantilica.com/simple/
uv pip install quantilica-analytics --index-url https://index.quantilica.com/simple/
