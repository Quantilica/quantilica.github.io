Como funciona

Três passos entre você e a base de dados pública que precisa.

01
Instale

A CLI vem do PyPI; cada fonte é um plugin instalado sob demanda pelo nosso índice próprio.

02
Escolha a fonte

Doze domínios, um mesmo padrão de comando. Instale só o que vai usar.

03
Analise

Dados tipados e versionados no seu disco, prontos para Polars, DuckDB ou o que vier depois.

# CLI unificada e núcleo — direto do PyPI
pip install quantilica-cli (traz o quantilica-core)

# Fetchers sob demanda — via índice próprio
quantilica install bcb-sgs
quantilica install rtn

# Alternativa manual (sem a CLI), apontando pip/uv para o índice:
uv pip install rtn-fetcher --index-url https://index.quantilica.com/simple/
uv pip install quantilica-analytics --index-url https://index.quantilica.com/simple/

Do download ao DataFrame

Fluxo completo com o INMET: baixa, tratamento e exportação direta para Parquet — pronto para análise.

# Baixa 5 anos do BDMEP em paralelo…
inmet-fetcher sync 2020:2024 -o ./dados --workers 4

# …e exporta unificado em Parquet (snake_case, datetime nativo)
inmet-fetcher read -o ./dados --uf SP,RJ --save-as sudeste.parquet
# sudeste.parquet
import polars as pl

df = pl.read_parquet("sudeste.parquet")
print(df.group_by("uf").len())

Retry automático, verificação de integridade e manifestos de proveniência acontecem em todas as etapas — sem configuração extra.

Antes e depois

O que muda no seu dia a dia quando a coleta deixa de ser manual.

Sem Quantilica

  • Baixar CSV e ZIP manualmente em portais diferentes
  • Limpar layout de largura fixa e dicionários em PDF
  • Conferir schema toda vez que a fonte muda de lugar
  • Reconstruir o histórico quando o link quebra
  • Responder "de onde veio esse número?" de memória

Com Quantilica

  • quantilica install <fonte> e um comando de sync
  • Saída tipada em Parquet, pronto para Polars
  • Manifest SHA-256 registrando cada download
  • Histórico versionado no seu disco — reprodutível
  • Proveniência auditável em arquivo, não de memória

Para quem é

Feito para quem transforma dado público em resposta.

Pesquisador — referencie exatamente o conjunto de dados usado: o hash SHA-256 do manifesto garante que a replicação encontra os mesmos arquivos.

Jornalista de dados — da pauta à série histórica sem raspar portal: o comando certo já sabe onde o dado mora e como ele mudou de layout.

Analista — séries tipadas e consistentes entre domínios, prontas para alimentar notebook, dashboard ou pipeline de ML.

Estudante — curva de entrada baixa: Python básico e um comando por fonte. Veja os perfis completos na documentação.

Perguntas frequentes

Preciso de chave de API ou cadastro?

Não. Todas as fontes usam endpoints públicos e abertos dos órgãos oficiais.

Funciona no Windows, macOS e Linux?

Sim. A stack é Python ≥ 3.12 puro, sem dependências de sistema.

Quanto custa?

Nada. Código MIT, sem plano pago e sem telemetria.

Onde ficam os dados baixados?

No seu disco, sob seu controle — em Parquet/CSV acompanhados de manifestos .manifest.json com o hash SHA-256 de cada arquivo.

Como citar em uma publicação?

Cite o pacote, a versão e o repositório. O hash registrado no manifest permite reproduzir exatamente o mesmo conjunto de dados usado.
